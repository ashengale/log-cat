# 로그 발췌기 (Log Excerpt Studio)

로그를 블록 단위로 쌓아 발췌 이미지를 만드는 단일 페이지 웹앱입니다.
`index.html` 하나만 GitHub Pages에 올리면 동작합니다.

편집 UI는 [채팅 발췌기](https://mok0999.github.io/315/chat.html), 결과물 구조는
[52발췌기](https://mudoc087-rgb.github.io/quote-studio/)를 참고해 재구성했습니다.

## 배포

1. 저장소 루트에 `index.html` 업로드
2. **Settings → Pages** → Source `Deploy from a branch`, Branch `main / (root)`
3. `https://<사용자>.github.io/<저장소>/`

> 이미지 변환은 CDN(cdnjs)의 html2canvas 1.4.1을 씁니다. 외부 CDN이 막힌 환경이면
> 파일을 저장소에 함께 올리고 `<head>`의 script 경로만 바꾸세요.

## 화면

- **상단** — 작성 모드(일반 / 로그 / 메신저), 이미지 복사, 이미지 저장
- **왼쪽(모바일은 위)** — 결과물. 줌(− 맞춤 ＋), 여러 개 선택, 순서 바꾸기, 분할 저장, HTML, 전부 지우기
- **오른쪽(모바일은 아래 시트)** — 작성 카드 + 도구 아코디언.
  PC는 경계선을 끌어 폭 조절, 모바일은 손잡이를 위로 끌어 높이 조절(짧게 누르면 접힘)

## 쓰는 순서

### 1. 블록 쌓기 (작성 카드)
종류를 고르고 내용을 넣은 뒤 **＋ 블록 추가** (`Ctrl/⌘+Enter`).

| 종류 | 설명 |
|---|---|
| 글 | 본문 문단 |
| 말풍 | 말풍선. `이름: 대사` 를 쓰면 발신자를 자동으로 찾고, 없으면 새 인물을 만듭니다 |
| 인용 | 왼쪽 강조선이 붙는 인용 문단 |
| 제목 / 부제 | 발췌 카드 머리말. 굵기 4단계 |
| 가름 | 구분선(실선 · 점선 · ···), 길이와 위아래 여백 조절 |
| 사진 | 이미지 블록. 자르기 · 크기 · 둥글기 |

여러 줄을 붙여넣으면 줄마다 블록으로 나뉩니다. `""` `( )` `*지문*` 버튼으로 기호를 감쌀 수 있습니다.

### 2. 결과물에서 직접 고치기
- 블록을 누르면 아래에 **블록 도구 바**가 열립니다: `B I S U`, 글자색, 보조색,
  형광 A·B·C, 강조선 A·B, 서식 해제, 위 · 아래 · 복제 · ✂ · 삭제
- 글은 결과물 위에서 바로 타이핑해 고칩니다. 일부만 드래그해 선택하면 그 부분만 서식이 바뀝니다.
- `Enter` 로 같은 종류의 블록이 이어 만들어집니다.
- **여러 개 선택** — 블록을 눌러 표시하고 버튼을 다시 눌러 한 번에 삭제
- **순서 바꾸기** — 블록을 끌어 이동 (PC · 모바일 공통)

### 3. 스마트 하이라이트 (색 · 효과)
원문 기호는 그대로 두고 결과물에서만 처리합니다.

- **따옴표 감지** — `"대사"` → 따옴표 A색, `「대사」` → 따옴표 B색
- **괄호 감지** — `*지문*` `(지문)` → 괄호색
- **기호를 결과물에서 숨기기** — 기호만 눈에서 감춥니다. 원문은 보존되므로 언제든 다시 켤 수 있습니다.
- 말풍선은 `대사에 따옴표 남기기` 로 따로 제어합니다.
- `⚡ 자동 말풍선` — 대사가 있는 글 블록을 말풍선으로 일괄 변환
- `⚡ 자동 강조선` — 대사에 강조선 A를 일괄 적용

### 4. 도구 아코디언
- **인물** — 이름 · 별명(같이 인식할 다른 표기) · 기본 위치 · 이름색 · 말풍선색 · 글자색 · 대사색 · 프사(원형 크롭)
- **캔버스 · 여백** — 비율(자동 / 1:1 / 4:5 / 3:4 / 16:9 / 9:16), 전체 너비, 가로 · 세로 여백,
  **책 내지 2열** 레이아웃과 단 간격
- **테마 · 배경** — 단색 / 2색 / 3색 그라데이션 / 이미지, 프리셋(흰 · 종이 · 먹 · 밤),
  이미지 크기 · 위치 · 블러 · 오버레이
- **텍스트 · 간격** — 서체, 굵기, 정렬, 줄바꿈 방식, 크기 · 자간 · 행간 · 문단 · 장평, 제목/부제 크기와 간격
- **말풍선** — 테마(기본 · 모서리 · 카드), 꼬리, 묶기, 프사 · 이름 표시, 크기 · 안쪽 여백 · 둥글기 · 최대 폭
- **색 · 효과** — 글자색, 보조색, 강조선 A·B, 형광 A·B·C, 따옴표 · 괄호색, 글자 그림자
- **저장 · 서명 · 프리셋** — 파일명, 배율(1~4×), PNG/JPG, 배경 투명, 서명(좌/우 문구), 페이지 번호,
  디자인 프리셋, JSON 백업

### 5. 저장
- **이미지 저장** — 배율만큼 확대해 렌더링(PNG는 무손실)
- **이미지 복사** — 클립보드로 바로 (지원 브라우저)
- **분할 저장** — ✂ 로 나눈 페이지를 각각 저장
- **HTML** — 카드 하나를 독립 HTML로 내보내기

## 알아둘 점
- 블록과 설정은 자동 저장되고, 새로고침 · 탭 닫기 직전에도 기록되므로 마지막 상태가 복원됩니다.
- 이미지(배경 · 프사 · 사진)는 브라우저 저장 공간(약 5MB)을 함께 씁니다. 부족하면 안내가 뜨니 JSON 백업을 쓰세요.
- 시크릿 모드에서는 자동 저장이 세션 안에서만 유지됩니다.
